### پیش‌نیازهای آموزش

برای درک بهتر مطالب این مخزن، آشنایی با سه حوزه زیر ضروری است.

**۱. ریاضیات پایه**

نام انگلیسی: ‎Mathematics‎

- جبر خطی (ماتریس، بردار، ضرب ماتریسی)
- حساب دیفرانسیل (مشتق، مشتق جزئی)
- آمار و احتمال (میانگین، واریانس، توزیع نرمال)
- مفاهیم پایه بهینه‌سازی

**۲. برنامه‌نویسی پایتون**

نام انگلیسی: ‎Python Programming‎

- متغیرها و انواع داده
- ساختارهای کنترلی (شرط، حلقه)
- توابع و کلاس‌ها
- برنامه‌نویسی شیءگرا
- مدیریت خطاها و استثناها

**۳. کتابخانه‌های علمی پایتون**

نام انگلیسی: ‎Scientific Python Libraries‎

- ‎NumPy‎ — محاسبات عددی و ماتریسی
- ‎Matplotlib‎ — رسم نمودار
- ‎Pandas‎ — پردازش داده
- ‎scikit-learn‎ — ابزارهای یادگیری ماشین
